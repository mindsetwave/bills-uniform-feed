# Bills Uniform Feed

Machine-readable feed of announced Buffalo Bills uniform combinations for
the 2026 season, consumed by the MindWave team app.

`bills-uniforms-2026.json` is regenerated daily by a GitHub Action that
reads the [Gridiron Uniform Database](https://www.gridiron-uniforms.com/)
Bills season page and translates its uniform codes. Games not yet
announced are simply absent from the file.

Uniform names: `homeRoyal`, `allBlue`, `roadWhite`, `allWhite`,
`throwbackRed`, `classicGrey`.

Data source credit: gridiron-uniforms.com. This feed is a small
non-commercial convenience for a team app.
